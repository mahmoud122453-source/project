# تشغيل مشروع الآلة الحاسبة

دليل تشغيل مبني على المشروع الحقيقي: مستودع [BaseMax/TkinterCalculator](https://github.com/BaseMax/TkinterCalculator) والملف `app.py`.

## 1. فكرة المشروع

تطبيق آلة حاسبة رسومية بلغة Python ومكتبة Tkinter (مدمجة مع Python على Windows).

النافذة عنوانها `Calculator`، حجمها الثابت `375x667`، وتعرض:

- شاشة علوية للتعبير الكامل (`total_expression`)
- شاشة سفلية للمدخل الحالي (`current_expression`)
- أزرار الأرقام والنقطة والعوامل والوظائف الخاصة: `C`، `x²`، `√x`، `=`

المشروع ملف بايثون واحد: `app.py`. لا يوجد `requirements.txt`.

## 2. المتطلبات

- نظام تشغيل يدعم Tkinter (تم التحقق على Windows 10)
- Python 3 مع وحدة `tkinter`
- لا مكتبات pip إلزامية لتشغيل التطبيق

اختياري فقط (موثّق في README الأصلي، وليس مطلوبًا للتدريس): `pyinstaller` لبناء ملف تنفيذي.

## 3. Python version

تم الاختبار الفعلي على:

```text
Python 3.12.0
C:\Users\DELL\AppData\Local\Programs\Python\Python312\python.exe
```

تحقق من إصدارك:

```powershell
python --version
```

## 4. Tkinter

Tkinter جزء من تثبيت Python القياسي على Windows. لا تثبّت حزمة pip باسم `tkinter`.

تحقق:

```powershell
python -c "import tkinter; print(tkinter.TkVersion)"
```

النتيجة المتوقعة (تم التحقق): رقم إصدار مثل `8.6`.

إذا فشل الاستيراد على نظام آخر، أعد تثبيت Python مع خيار Tcl/Tk، أو ثبّت حزمة النظام المناسبة (مثل `python3-tk` على بعض توزيعات Linux). هذا المشروع لا يضيف تلك الحزمة بنفسه.

## 5. إنشاء virtual environment إذا كان مناسبًا

المشروع لا يحتاج حزم خارجية. البيئة الافتراضية اختيارية للتنظيم في الصف، وليست شرط تشغيل.

من مجلد المشروع:

```powershell
python -m venv .venv
```

## 6. تفعيل البيئة في Windows

PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

Command Prompt:

```cmd
.venv\Scripts\activate.bat
```

إذا ظهرت سياسة تنفيذ سكربتات في PowerShell، يمكنك تشغيل المشروع بدون venv باستخدام `python` العام كما تم في الاختبار.

## 7. تثبيت dependencies إن وجدت

لا توجد اعتماديات pip للتشغيل. لا يوجد ملف `requirements.txt`.

لا تنفّذ `pip install tkinter`.

## 8. تشغيل المشروع

من جذر المشروع (المجلد الذي فيه `app.py`):

```powershell
python app.py
```

هذا الأمر تم تنفيذه فعليًا: تُنشأ النافذة ثم تدخل `mainloop` عبر `TkinterCalculator.run()`.

عند التشغيل يظهر:

- عنوان النافذة: `Calculator`
- الحجم: `375x667`
- النافذة غير قابلة لتغيير الحجم (`resizable(0, 0)`)

## 9. طريقة استخدام الآلة الحاسبة

1. شغّل `python app.py`.
2. أدخل رقمًا من الأزرار أو من لوحة المفاتيح (الأرقام `0`–`9` والنقطة `.`).
3. اضغط عاملًا: `+` أو `-` أو `×` أو `÷`.
4. أدخل الرقم التالي.
5. اضغط `=` أو مفتاح Enter/`Return` للحساب.
6. اضغط `C` لمسح الشاشتين.
7. استخدم `x²` لتربيع القيمة الحالية، و`√x` للجذر التربيعي للقيمة الحالية.
8. أغلق النافذة من زر الإغلاق في شريط العنوان.

لا يوجد زر أو اختصار Backspace في هذا المشروع.

## 10. العمليات المدعومة

| العملية | الزر / الرمز الظاهر | القيمة الداخلية في الكود |
|---------|---------------------|--------------------------|
| جمع | `+` | `+` |
| طرح | `-` | `-` |
| ضرب | `×` (`\u00D7`) | `*` |
| قسمة | `÷` (`\u00F7`) | `/` |
| تربيع | `x²` | `current ** 2` عبر `eval` |
| جذر تربيعي | `√x` | `current ** 0.5` عبر `eval` |
| يساوي | `=` أو Enter | `eval(total_expression)` |
| مسح | `C` | يفرّغ التعبيرين |

غير موجود في المشروع: Backspace، زر إشارة `+/-` مستقل، مفتاح Escape، زر `%`.

## 11. اختبار العمليات

جرب يدويًا بعد التشغيل:

1. `1` `2` `3` → الشاشة السفلى `123`
2. `2` `+` `3` `=` → `5`
3. `9` `-` `4` `=` → `5`
4. `6` `×` `7` `=` → `42`
5. `8` `÷` `2` `=` → `4.0`
6. `1` `+` `2` `×` `3` `=` → `7` (أولوية `eval` في Python: الضرب قبل الجمع)
7. `C` → الشاشتان فارغتان
8. `9` ثم `√x` → `3.0`
9. `5` ثم `x²` → `25`
10. من لوحة المفاتيح: `7` ثم `8` → `78`
11. `2` `+` `2` ثم Enter → `4`
12. `5` `÷` `0` `=` → `Error`
13. `+` ثم `=` → `Error`

## 12. المشاكل الشائعة

- الأمر `python` غير معروف
- `No module named tkinter`
- النافذة لا تظهر لأنك لست في مجلد المشروع
- بعد رسالة `Error` الضغط على رقم يلصق النص `Error` مع الرقم (سلوك الكود الحالي)
- `0.1 + 0.2` يعطي `0.30000000000000004` بسبب أعداد IEEE العشرية عبر `eval`

## 13. حلول المشاكل

| المشكلة | الحل |
|---------|------|
| `python` غير معروف | ثبّت Python وفعّل Add to PATH، أو استخدم `py app.py` |
| Tkinter مفقود | أعد تثبيت Python مع Tcl/Tk؛ لا تستخدم pip باسم tkinter |
| ملف غير موجود | `cd` إلى المجلد الذي يحتوي `app.py` |
| النافذة خلف نوافذ أخرى | انظر شريط المهام؛ العنوان `Calculator` |

## 14. أخطاء الحساب

الحساب يتم بـ `eval()` على سلسلة نصية.

- القسمة على صفر داخل `evaluate()` تظهر `Error` ولا تُسقط البرنامج.
- التعبير غير الصالح داخل `evaluate()` يظهر `Error`.
- `square()` و`sqrt()` بعد التصحيح الضروري يعرضان `Error` إذا كان المدخل فارغًا أو غير صالح، بدل إيقاف التطبيق.
- `eval` ينفّذ تعبير Python؛ هذا مناسب للآلة الحاسبة التعليمية الصغيرة، وهو غير آمن لإدخال حر من مستخدم غير موثوق في تطبيقات حقيقية.

## 15. مشاكل Tkinter

- على Windows مع مثبت python.org عادة يعمل `import tkinter` مباشرة.
- إذا فُتح الطرفية ولم تظهر نافذة: تأكد أنك لا تعمل في جلسة بدون واجهة رسومية.
- المشروع يستدعي `self.window.mainloop()` داخل `run()`؛ لا تغلق الطرفية قبل إغلاق النافذة إذا شغّلت التطبيق يدويًا.

## 16. طريقة إغلاق التطبيق

أغلق نافذة `Calculator` من زر الإغلاق (X). ذلك ينهي `mainloop` ويعيد التحكم إلى الطرفية.

لا يوجد ربط لمفتاح Escape في الكود.
