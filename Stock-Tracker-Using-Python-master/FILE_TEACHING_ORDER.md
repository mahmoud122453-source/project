## ما لا يُعطى كمنهج عميق

- لا يوجد `LICENSE` في هذه النسخة.
- لا توجد صور محلية؛ الخلفية رابط خارجي في CSS.
- لا توجد اختبارات وحدة.
- لا توجد طبقة API خاصة بالمشروع.

## ترتيب الاستلام المقترح للحصة

1. تشغيل وفق `RUN_GUIDE.md` ومشاهدة `AAPL`.
2. قراءة `README.md` لربط ما شوهد بالوصف الأصلي.
3. فتح `requirements.txt` ثم `import` في أعلى `app.py`.
4. دراسة `app.py` بالكامل (36 سطراً).
5. العودة إلى الخرائط (`PROJECT_MAP.md`) لترسيخ التدفق.
