# ترتيب ملفات التدريس

المصدر الأصلي للمستودع: أربعة ملفات فقط. أُضيفت ملفات الدليل التعليمية بعد التحقق. لا يوجد `LICENSE` في المستودع.

## ماذا يستلم الطالب وبأي ترتيب

### 1) `sales.csv` — أولاً (قبل أي كود)

- الدور: المادة الخام
- لماذا أولاً: كل رقم لاحق يأتي من هذه الصفوف
- ماذا يُلاحظ: ترويسة `Date,Product,Region,Sales` ثم 12 صف بيانات
- ماذا لا يُعطى بعد كحقيقة: وصف README إن خالف الملف
- عيب أصلي للدرس: سطر `// This is just an sample data.` كان يكسر التحميل؛ الملف المصحح يبدأ بالترويسة
- مستوى: مبتدئ — واجب إتقان قراءة الجدول بالعين

### 2) `README.md` — ثانياً وبتحفظ

- الدور: نية المؤلف وأمر التشغيل
- يُستخدم لـ: `python sales-analysis.py`، فكرة pandas + matplotlib
- لا يُستخدم كمصدر حقائق للبيانات دون فتح CSV
- أخطاء موثَّقة في README نفسه: رابط clone فيه `your-username//Analysis-CSV.git`، واسم مجلد `Analysis-CSV/` لا يطابق مجلد العمل الحالي
- مستوى: مبتدئ — قراءة أوامر، ليس تصديق كل جملة

### 3) `requirements.txt` — ثالثاً

- الدور: اعتماديتان بدون إصدار
- المحتوى الفعلي: `pandas` ثم `matplotlib`
- التدريس: الاستيراد يحتاج تثبيتاً؛ لا تثبيت أعمى إن كان الاستيراد ينجح
- مستوى: مبتدئ

### 4) `sales-analysis.py` — رابعاً (الملف المركزي)

يُدرَّس على كتل بالترتيب داخل الملف (انظر أيضاً PROJECT_MAP):

| الترتيب | الأسطر | الكتلة |
|---------|--------|--------|
| 4.1 | 1–2 | الاستيراد |
| 4.2 | 4–7 | التحميل |
| 4.3 | 9–14 | المعاينة |
| 4.4 | 16–22 | الإحصاء |
| 4.5 | 24–36 | groupby والتاريخ |
| 4.6 | 38–55 | الرسوم و`show` |

- لا دوال لتأخيرها
- مستوى الكتل الأولى: مبتدئ؛ groupby والتاريخ: متوسط؛ تفسير محدودية الخط: متوسط

### 5) `RUN_GUIDE.md` — بعد فهم الملفات الأربعة

- متى: عند التشغيل الأول وبعد أي فشل
- اللغة: العربية
- لا يُستبدل بالكود

### 6) `TEACHING_GUIDE.md` — للمدرّس / المسار التعليمي

- متى: لتخطيط الحصة وتمارين الإتقان
- بعد أن يرى الطالب CSV والكود مرة واحدة

### 7) `PROJECT_MAP.md` و`FILE_TEACHING_ORDER.md`

- متى: للمراجعة وخريطة الاعتماد
- ليس نقطة دخول للطالب المبتدئ في اليوم الأول

## ما لا يُعطى كجزء من المشروع الأصلي

- مجلد `venv` (اختياري حسب README؛ غير موجود في المستودع)
- ملفات صور محفوظة (`savefig` غير مستخدم)
- اختبارات وحدة (غير موجودة)
- ترخيص (غير موجود في قائمة ملفات GitHub)
