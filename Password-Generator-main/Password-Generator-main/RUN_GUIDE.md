# 1. اسم المشروع

Random Password Generator (مولّد كلمات المرور العشوائية)

# 2. فكرة المشروع

برنامج بايثون بسيط يعمل من سطر الأوامر. يطلب من المستخدم إدخال طول كلمة المرور، ثم يولّد كلمة مرور عشوائية من الحروف الكبيرة والصغيرة والأرقام والرموز الخاصة، ويعرضها على الشاشة.

# 3. المتطلبات

- نظام تشغيل Windows
- تثبيت Python 3
- لا توجد مكتبات خارجية مطلوبة

# 4. إصدار Python

- الإصدار الذي تم التحقق منه أثناء التشغيل: Python 3.12.0
- الإصدار الموصى به: Python 3.x (أي إصدار حديث من بايثون 3)

# 5. فتح المشروع

1. افتح مجلد المشروع. إذا نزّلت الملف المضغوط، فستجد الملفات داخل المجلد:
   `Password-Generator-main`
2. تأكد أن هذا المجلد يحتوي على الملف `main.py`.
3. داخل المجلد اضغط Shift + زر الفأرة الأيمن واختر **Open PowerShell window here**، أو افتح PowerShell / CMD ثم انتقل للمجلد:

```bat
cd D:\project_lv3\Password-Generator\Password-Generator-main
```

غيّر المسار أعلاه إلى المسار الفعلي على جهازك.

# 6. البيئة الافتراضية

هذا المشروع يعتمد فقط على مكتبات بايثون القياسية، لذلك **ليست البيئة الافتراضية ضرورية للتشغيل**.

إذا أردت إنشاء بيئة افتراضية للتدريب على بيئة بايثون، يمكنك ذلك اختيارياً:

```bat
python -m venv .venv
```

# 7. تفعيل البيئة الافتراضية

إذا أنشأت البيئة الافتراضية، فعّلها في PowerShell بهذا الأمر:

```bat
.venv\Scripts\Activate.ps1
```

أو في Command Prompt:

```bat
.venv\Scripts\activate.bat
```

إذا ظهرت رسالة تمنع تشغيل السكربت في PowerShell، يمكنك تشغيل البرنامج مباشرة بدون تفعيل البيئة، لأن المشروع لا يحتاج مكتبات إضافية.

# 8. تثبيت المكتبات

لا يحتاج هذا المشروع إلى تثبيت مكتبات خارجية،
لأنه يعتمد فقط على مكتبات Python القياسية.

المكتبات المستخدمة داخل الكود:

- `random`
- `string`

# 9. تشغيل المشروع

من داخل مجلد `Password-Generator-main` نفّذ الأمر التالي (وهو الأمر الذي تم تشغيله بنجاح):

```bat
python main.py
```

إذا لم يعمل الأمر `python`، جرّب:

```bat
py main.py
```

# 10. ماذا يحدث عند التشغيل؟

1. تظهر رسالة العنوان: Random Password Generator.
2. يطلب البرنامج إدخال طول كلمة المرور:
   `Enter Password Length:`
3. تدخل رقماً صحيحاً (الحد الأدنى في البرنامج هو 4).
4. يختار البرنامج حروفاً عشوائية من مجموعة تحتوي على:
   - حروف إنجليزية كبيرة وصغيرة
   - أرقام
   - رموز خاصة
5. تُعرض كلمة المرور الناتجة في سطر يبدأ بـ:
   `Your Password :`

إذا كان الطول أقل من 4 تظهر رسالة توضح أن الطول يجب ألا يقل عن 4.

إذا أدخلت نصاً بدل رقم تظهر الرسالة:
`Please enter valid number`

# 11. مثال عملي

تشغيل البرنامج:

```text
python main.py
```

تفاعل تقريبي:

```text
🔐 Random Password Geberator
Enter Password Length: 12
✅ Your Password : wQ#o^1:r&;s:
```

ملاحظات المثال:

- الرقم `12` أدخله المستخدم.
- كلمة المرور المعروضة **مثال فقط**؛ الناتج يتغير في كل تشغيل لأن التوليد عشوائي.
- طول الناتج يساوي الطول الذي أدخلته (هنا 12 حرفاً).

مثال آخر: إذا أدخلت `3` فلن تُولَّد كلمة مرور، وستظهر رسالة الحد الأدنى.

# 12. المشاكل الشائعة وحلولها

## الأمر python غير معروف

الرسالة قد تكون مثل: `python is not recognized`.

الحل:

- ثبّت Python 3 من الموقع الرسمي.
- أثناء التثبيت فعّل خيار Add Python to PATH.
- أو استخدم الأمر `py main.py`.

## التشغيل من مجلد خاطئ

إذا ظهر خطأ أن الملف غير موجود، فأنت لست داخل مجلد المشروع.

الحل:

```bat
cd مسار\مجلد\Password-Generator-main
python main.py
```

وتأكد أن `main.py` موجود في نفس المجلد.

## استخدام أمر بايثون غير الصحيح

على بعض الأجهزة يعمل `py` ولا يعمل `python`، أو العكس.

جرّب الاثنين:

```bat
python main.py
py main.py
```

## إدخال غير رقمي

إذا كتبت حروفاً مثل `abc` فلن يتوقف البرنامج بشكل مفاجئ، بل يعرض:

```text
❌ Please enter valid number
```

هذا سلوك طبيعي في المشروع الحالي.

## الطول أقل من 4

إذا أدخلت `0` أو `3` أو رقماً سالباً، يظهر:

```text
❌ Password length must be at least 4.
```

أدخل رقماً أكبر من أو يساوي 4.
