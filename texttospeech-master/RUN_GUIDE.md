# دليل التشغيل — تطبيق تحويل النص إلى كلام

هذا الدليل مبني على تشغيل المشروع الفعلي على الجهاز، وليس على افتراضات.

## 1. المتطلبات

- نظام التشغيل المختبر: **Windows 10 Pro 64-bit** (الإصدار 10.0.19045)
- **Python 3.12** (تم الاختبار على 3.12.0)
- مكتبة الواجهة **Tkinter** تأتي مع تثبيت Python الرسمي لويندوز (لا تُثبَّت عبر `pip install tkinter`)
- حزمة **pyttsx3** ومحرك الكلام المحلي لنظام ويندوز **SAPI5**
- مجلد الصور `images/` ويجب أن يحتوي على:
  - `speak.png`
  - `download.png`
  - `speaker logo.png`

المشروع يعمل بدون إنترنت بعد تثبيت الحزم. جودة الكلام العربي تعتمد على الأصوات المثبتة في ويندوز، وليست ميزة داخل كود المشروع.

## 2. نسخة Python المختبرة

```text
Python 3.12.0
pip 26.1 (النظام) ثم pip 26.2.1 داخل البيئة الافتراضية
```

أمر التحقق:

```bat
python --version
python -m pip --version
```

## 3. التثبيت

1. نزّل المشروع أو انسخه إلى مجلد محلي.
2. افتح موجه الأوامر داخل مجلد المشروع (المجلد الذي فيه `main.py`).
3. تأكد أن الملفات التالية موجودة:

```text
main.py
requirements.txt
README.md
images\speak.png
images\download.png
images\speaker logo.png
```

## 4. البيئة الافتراضية (موصى بها)

المشروع الأصلي لم يكن يحتوي على بيئة افتراضية. تم إنشاؤها محلياً للاختبار حتى لا تختلط الحزم مع باقي النظام.

```bat
python -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
```

إذا لم تستخدم بيئة افتراضية يمكنك تثبيت الحزم على Python النظام، لكن هذا أقل أماناً لتنظيم المشاريع التعليمية.

## 5. تثبيت الاعتماديات

استخدم ملف المشروع فقط:

```bat
python -m pip install -r requirements.txt
```

محتوى `requirements.txt` الفعلي:

```text
comtypes==1.4.11
pyttsx3==2.98
pywin32
```

عند التثبيت على ويندوز ظهرت أيضاً الحزمة التابعة `pypiwin32`.

تحقق من Tkinter وpyttsx3:

```bat
python -c "import tkinter; print(tkinter.TkVersion)"
python -c "import pyttsx3; print('pyttsx3 OK')"
```

لا تثبّت حزمة اسمها `tkinter` من pip على ويندوز إلا إذا واجهت بيئة خاصة تتطلب ذلك. في الاختبار: `tkinter 8.6` كان متوفراً مع Python.

## 6. أمر التشغيل

من مجلد المشروع، وبعد تفعيل البيئة الافتراضية إن وُجدت:

```bat
python main.py
```

الأمر الذي تم اختباره بنجاح بعد تثبيت الاعتماديات:

```bat
.venv\Scripts\python.exe main.py
```

قبل تثبيت الحزم فشل الأمر نفسه بهذا الخطأ:

```text
ModuleNotFoundError: No module named 'pyttsx3'
```

## 7. الأخطاء الشائعة

| الخطأ | السبب | الحل |
| --- | --- | --- |
| `ModuleNotFoundError: No module named 'pyttsx3'` | لم تُثبَّت الاعتماديات | `python -m pip install -r requirements.txt` |
| `TclError` أو فشل `PhotoImage` | ملف صورة مفقود من `images/` | تأكد من وجود ملفات PNG الثلاثة |
| النافذة لا تظهر | تشغيل الأمر من مجلد آخر | `cd` إلى مجلد `main.py` |
| صوت أنثوي يسبب `IndexError` | الجهاز فيه صوت واحد فقط بينما الكود يستخدم `voices[1]` | ثبّت صوتاً ثانياً في ويندوز أو اختر Male |
| الملف المحفوظ `text.mp3` لا يعمل في بعض المشغلات | المحرك يحفظ بيانات WAV مع امتداد mp3 | شغّل الملف بمشغّل يدعم WAV أو غيّر الامتداد إلى `.wav` للتجربة |
| النص العربي لا يُنطق بوضوح | أصوات ويندوز المثبتة إنجليزية (David / Zira في جهاز الاختبار) | هذه حدود نظام التشغيل وليست خطأ في زر Speak |

## 8. استكشاف الأخطاء

1. شغّل `python main.py` من مجلد المشروع وليس من مجلد أعلى.
2. إذا فشل الاستيراد: فعّل `.venv` ثم أعد تثبيت `requirements.txt`.
3. إذا فشل تحميل الأيقونة: اطبع المسار الناتج عن `resource_path("images/speak.png")` وتأكد أن الملف موجود.
4. إذا لم يُسمع صوت: افحص مستوى صوت النظام، وتأكد أن محرك SAPI5 يعمل (أصوات Windows Speech).
5. أثناء النطق تتجمد الواجهة مؤقتاً. هذا سلوك أصلي لأن `engine.runAndWait()` يعمل على نفس خيط Tkinter. لا يعني أن البرنامج توقف نهائياً.

## 9. النتيجة المتوقعة

- تظهر نافذة بعنوان **Text to Speech**
- الحجم المعرّف في الكود: **900x450** وغير قابلة للتكبير
- خلفية داكنة `#305065` وشريط علوي أبيض
- صندوق نص كبير على اليسار
- قائمتان: Voice (`Male` / `Female`) و Speech (`Fast` / `Normal` / `Slow`)
- زر **Speak** وزر **Save**
- بعد كتابة نص إنجليزي والضغط على Speak يُسمع الكلام عبر محرك ويندوز
- زر Save يفتح اختيار مجلد ثم يكتب ملفاً اسمه `text.mp3`

لا يوجد في الكود: شريط مستوى الصوت، زر إيقاف النطق، أو دعم لغات صريح.
