# ترتيب تدريس الملفات

## ترتيب الاعتماد عند التشغيل

هذا ترتيب الاستيراد الفعلي، لا ترتيب الشرح:

1. `log_code.py`  
   `app.py` و`news_summarizer.py` ينفذان `from log_code import Logger` قبل أي تلخيص.
2. `news_summarizer.py`  
   عند الاستيراد: تنزيل بيانات NLTK، ثم `spacy.load("en_core_web_sm")`، ثم تعريف `summarize_news`.
3. `app.py`  
   يستورد `summarize_news` ويستدعيها من زر Streamlit.
4. `log_files/*.log`  
   ناتج الكتابة، وليست مصدرًا يُستورد.

`Requirements.txt` شرط تثبيت قبل التشغيل، وليس ملف استيراد.

`display_result` لا تستدعيها الواجهة. تستدعيها كتلة `if __name__ == "__main__"` في وضع الطرفية.

## ترتيب التدريس

ابدأ بمحرك التلخيص، لا بالمُسجّل. المُسجّل يُستورد أولًا لكنه لا يفسر الدرجة.

| الترتيب | الملف | السبب |
| ---: | --- | --- |
| 1 | `news_summarizer.py` | فيه الاستخراج والتكرار والتطبيع والتسجيل والترتيب والكيانات |
| 2 | `app.py` | يمرر الرابط وعدد الجمل ويعرض القاموس الراجع |
| 3 | `Requirements.txt` | يفسر ما يجب تثبيته، بما فيه `click==8.1.7` لأمر نموذج spaCy |
| 4 | `log_code.py` ثم `log_files/` | مستوى السجل، مسار الملف، وأن الرابط يُسجل عمدًا |
