# دليل التشغيل — تتبع جسم حسب اللون

هذا الدليل يصف التشغيل الذي جُرّب على هذا الجهاز. الأوامر المكتوبة هنا نُفذت، والنتيجة مذكورة بجانبها.

## البيئة التي تم الاختبار عليها

| البند | القيمة |
| --- | --- |
| نظام التشغيل | Windows 10 (10.0.19045) |
| Python | 3.12.0 |
| pip | 26.1 |
| OpenCV | 4.13.0 (`opencv-python`) |
| NumPy | 1.26.2 |
| بيئة افتراضية | غير موجودة. التشغيل تم ببايثون النظام |
| الكاميرا | الفهرس `0` يفتح ويعيد إطارات `480×640×3` |

لا يوجد ملف `requirements.txt`. الاعتماديات الفعلية في السكربت هي: `opencv-python` و`numpy`، بالإضافة إلى مكتبات بايثون القياسية `argparse` و`sys` و`time` و`collections`.

## التثبيت

تحقق أولاً من أن الحزم موجودة:

```bash
python --version
python -c "import cv2, numpy; print(cv2.__version__, numpy.__version__)"
```

على هذا الجهاز نجح الأمر الثاني وطبع `4.13.0` و`1.26.2`. لم تُثبَّت حزم جديدة.

إذا فشل الاستيراد على جهاز آخر:

```bash
pip install opencv-python numpy
```

هذا أمر التثبيت المكتوب في المشروع. لم تُحتَج إليه هنا.

بيئة افتراضية اختيارية، ولم تُستخدم في الاختبار:

```bash
python -m venv .venv
.venv\Scripts\activate
pip install opencv-python numpy
```

## اسم الملف

اسم السكربت الحقيقي هو:

```text
object tracking based on colour.py
```

فيه مسافات. الأمر المكتوب قديماً باسم `object_tracking_based_on_colour.py` لا يعمل، لأن ذلك الملف غير موجود.

شغّل الأوامر من مجلد المشروع، وضع اسم الملف بين علامتي اقتباس.

## متطلبات الكاميرا

- كاميرا يراها OpenCV على الفهرس `0`. المشروع لا يملك وسيطاً لتغيير رقم الكاميرا.
- إضاءة كافية، والجسم المطلوب بلون مختلف عن الخلفية.
- وضع `--demo` لا يحتاج كاميرا.

## وضع العرض التجريبي

```bash
python "object tracking based on colour.py" --demo
```

النتيجة المختبرة:

- تظهر نافذة `Color Tracker` ونافذة `HSV Tuner`.
- تُرسم كرة حمراء تتحرك على مسار منحني فوق خلفية رمادية.
- الحالة على الشاشة تكون `TRACKING` مع دائرة ومركز ومسار.
- الكرّة التجريبية حمراء فقط. `--color green` مع `--demo` يفتح البرنامج ويبقى في `SEARCHING` لأن الكرة ليست خضراء.

## الكاميرا

```bash
python "object tracking based on colour.py"
```

النتيجة المختبرة: النافذتان تفتحان، صورة الكاميرا تظهر، ومعدل الإطارات في التجربة كان حوالي 43. اللون الابتدائي أحمر. في المشهد الذي كانت الكاميرا تراه لم توجد منطقة حمراء كبيرة، فظهرت الحالة `SEARCHING...`. إغلاق النافذة بمفتاح ESC أنهى البرنامج وطبع `[INFO] Tracker closed.`

لم يُجرَّب تحريك جسم ملون بيدك أمام الكاميرا. اختبار الألوان الخمسة على كرات مصطنعة نجح داخل خط المعالجة نفسه.

## ملف فيديو

```bash
python "object tracking based on colour.py" --video path\to\video.mp4
```

جُرّب بفيديو محلي قصير صُنع للاختبار: كرة حمراء تتحرك على خلفية رمادية، بترميز MJPG. البرنامج فتح الملف، أظهر النافذتين، ثم طبع:

```text
[INFO] End of stream.
[INFO] Tracker closed.
```

وانتهى من نفسه برمز خروج `0`. لا تضع مسار فيديو غير موجود.

## اللون وطول المسار

```bash
python "object tracking based on colour.py" --color green
python "object tracking based on colour.py" --demo --color blue --trail 16
python "object tracking based on colour.py" --trail 128
```

القيم المقبولة لـ `--color`: `red` و`green` و`blue` و`yellow` و`orange`. القيمة الافتراضية `red`.

`--trail` عدد صحيح، والافتراضي `64`. هو أقصى عدد نقاط يحتفظ بها المسار.

جُرّبت أيضاً `--color green --trail 16` مع `--demo`، و`--trail 32` و`--trail 20` مع ملف فيديو. البرنامج قبلها وشغّل النافذة.

## مفاتيح لوحة المفاتيح

| المفتاح | الفعل | نتيجة الاختبار |
| --- | --- | --- |
| `q` | خروج | نجح عندما وصل الحرف اللاتيني `q`، والخروج طبع `Tracker closed.` |
| `ESC` | خروج | نجح، بما في ذلك تشغيل الكاميرا |
| `t` | إظهار أو إخفاء المسار | نجح. الشريط العلوي تغيّر إلى `Trail:OFF` واختفى الخط |
| `m` | إظهار القناع بجانب الصورة | نجح. ظهرت بقعة بيضاء على خلفية سوداء |
| `r` | مسح المسار | المفتاح يصل إلى الحلقة نفسها. أثره أوضح عندما يكون المسار ظاهراً وفيه نقاط |
| `1` إلى `5` | أحمر، أخضر، أزرق، أصفر، برتقالي | جُرّب `1` و`2` و`3`. يتغير الاسم في الشريط ويُطبع `[INFO] Switched to preset` |
| `SPACE` | إيقاف مؤقت أو متابعة | نجح. يظهر `[PAUSED]` وتتجمد الكرة ثم تعود الحركة |

على هذا الجهاز تخطيط لوحة المفاتيح عربي (`0x04012801`). مواضع الحروف تنتج حروفاً عربية، مثل أن موضع `t` يعطي `ف`. لذلك `q` و`t` و`m` و`r` لا تعمل إلا بعد التحويل إلى English. `ESC` والمسافة والأرقام `1`–`5` عملت مع هذا التخطيط.

`waitKey` ضروري لأن حلقة OpenCV لا تحدّث النوافذ ولا تقرأ المفاتيح من دونه. القيمة `1` تعني الانتظار ميلي ثانية واحدة تقريباً ثم المتابعة.

## ضبط HSV

نافذة `HSV Tuner` تفتح مع البرنامج. في البداية للون الأحمر ظهرت القيم:

- H Low = 0 ، H High = 10
- S Low = 120 ، S High = 255
- V Low = 70 ، V High = 255

لأي لون غير الأحمر، الحدود الستة كلها تدخل `cv2.inRange`. للأحمر، درجة اللون ثابتة في الكود: من 0 إلى 10 ومن 170 إلى 180. حرّك `S` و`V` للأحمر، ولا تتوقع أن شريطي `H` يغيّران قناعه.

إذا ظهر ضجيج: ارفع `S Low` لرفض الرمادي، وارفع `V Low` لرفض المظلم. خفض أحد الحدين الأدنى يُدخل خلفية أكثر.

المفاتيح `1`–`5` تعيد الأشرطة إلى قيم اللون المختار.

## أعطال معروفة وكيف تظهر

لون غير موجود في القائمة:

```bash
python "object tracking based on colour.py" --color purple
```

رمز الخروج `2`، و`argparse` يطبع الخيارات المسموحة.

قيمة غير رقمية لطول المسار:

```bash
python "object tracking based on colour.py" --trail abc
```

رمز الخروج `2`.

فيديو غير موجود، أو مصدر لا يفتح:

```bash
python "object tracking based on colour.py" --video D:\project_lv3\does_not_exist.mp4
```

يطبع `[ERROR] Cannot open source` ويقترح `--demo`، ثم يخرج بالرمز `1`. هذا نفس فرع الفشل المستخدم إذا لم تفتح الكاميرا. الكاميرا `0` كانت متاحة، لذلك لم يُشاهَد هذا الفرع على الكاميرا نفسها.

نهاية الفيديو ليست خطأ. الرسالة `[INFO] End of stream.` ثم إغلاق النوافذ وتحرير `VideoCapture`.

## ماذا تتوقع على الشاشة

- `TRACKING (cx,cy)` عندما توجد منطقة لونها ضمن المجال ومساحتها بعد التنظيف لا تقل عن 500 بكسل مربع.
- `SEARCHING...` عندما لا توجد منطقة مقبولة.
- `Mask:ON` يعرض الصورة والقناع جنباً إلى جنب. نافذة العرض مقاسها ثابت تقريباً `800×600`، لذلك الصورة المزدوجة تُضغط وقد تبدو الكرة بيضوية. هذا شكل العرض وليس شكل القناع.
- وضع العرض التجريبي أداة للشرح. لتجربة أخضر أو أزرق أو أصفر أو برتقالي أمام الكاميرا تحتاج جسماً بهذا اللون، لأن الكرة المصطنعة حمراء.
